# Review lessons

Keep this file in the project-owned `.memory/review-lessons.md`. Add a numbered
lesson when a review or test finds a new class of problem. Each lesson names the
ticket that taught it and states the prevention or verification rule.

## Seed lessons

1. Do not turn an error into a successful-looking default; report the failure.
   (Ticket: seed.)
2. Test failure paths, overlapping operations and immediate completion, not only
   the ordinary success path. (Ticket: seed.)
3. Record what was actually inspected or tested and what remains unverified.
   (Ticket: seed.)

Executors, Reviewers and the optional Critical Friend read this file before work.
Keep lessons concise, project-owned and technology-neutral.
